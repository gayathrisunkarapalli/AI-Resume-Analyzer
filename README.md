# AI Resume Analyzer and Job Recommendation System

## 1. Project Overview
This project is an NLP-based career guidance application. It accepts PDF or DOCX resumes, extracts and cleans resume text, identifies technical skills, compares the resume with predefined job-role requirements, recommends the top roles, identifies skill gaps, and generates a simple learning roadmap.

## 2. Technologies Used
- Python
- Streamlit
- pypdf
- python-docx
- Pandas / NumPy
- Scikit-learn
- TF-IDF and cosine similarity
- Plotly

## 3. Features
1. PDF/DOCX resume upload
2. Resume text extraction
3. Text cleaning and normalization
4. Skill extraction using a controlled skill dictionary
5. 8 predefined job roles
6. Resume/job-role similarity scoring
7. Top 3 job-role recommendations
8. Skill-gap analysis
9. Week-by-week learning roadmap
10. Responsible AI notice

## 7. Methodology
### Text extraction
- PDF: pypdf
- DOCX: python-docx

### Skill extraction
A controlled dictionary of technical skills is loaded from CSV. Skills are detected with case-insensitive regular expressions.

### Job matching
TF-IDF converts the resume text and each role's required-skill text into vectors. Cosine similarity produces a similarity score that is displayed as a percentage estimate.

### Roadmap
For a selected role, required skills are compared against detected skills. Up to six missing skills are converted into weekly learning tasks.

## 8. Limitations
- Keyword-based skill extraction can miss skills expressed using unusual wording.
- TF-IDF similarity is a lexical method and does not fully understand semantic meaning.
- Match scores are estimates, not hiring decisions.
- The current roadmap is rule-based rather than generated by an advanced learning model.
- A resume may contain abilities that are not represented by keywords.

## 9. Responsible AI
This application is intended for career guidance. It should not be used to automatically hire, reject, rank, or discriminate against people. It focuses on job-related resume information and should not evaluate protected or unrelated personal attributes.
